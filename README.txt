This folder is the AHS Tryout Tracker, ready to put on a web address so that
phones and tablets can install it.

  index.html               the whole app (same file as "AHS Tryout Tracker.html")
  manifest.webmanifest     name, colours and icons for the installed app
  sw.js                    lets it open and work with no signal
  icon-*.png               home-screen icons
  apple-touch-icon.png     home-screen icon for iPhone and iPad

Upload all of it, keeping the names. Then open the address on the device and
add it to the home screen. Built 20260901-093239.
